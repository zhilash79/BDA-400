# Customer Purchasing Trends Analysis in R

## Project Overview

This project analyzes customer purchasing trends using a synthetic retail sales dataset. The goal is to identify purchasing patterns, understand product category performance, explore customer spending behavior, and analyze monthly revenue trends using R.

## Objectives

* Clean and prepare the retail sales dataset for analysis.
* Calculate summary statistics, including average purchase amounts.
* Identify top-performing product categories.
* Create exploratory data visualizations to reveal purchasing patterns.
* Analyze and model monthly revenue trends.

## Dataset

The project uses a synthetic retail sales dataset designed for analysis and practice.

The dataset supports the examination of customer purchases, product categories, purchase amounts, and revenue over time.

## Tools and Technologies

* **R:** Data analysis and statistical computing.
* **RStudio:** Development environment for R.
* **tidyverse:** Data manipulation and analysis workflows.
* **dplyr:** Data cleaning, filtering, grouping, and summarization.
* **ggplot2:** Data visualization and exploratory plots.
